# C++ Hash Table Implementation with Chaining

A high-performance data structure infrastructure project written in C++ that builds a custom Hash Table from scratch, featuring dynamic file parsing and advanced collision resolution.

## Technical Skills & Architecture
* **Collision Resolution Mechanics:** Engineered a robust bucket chaining system (separate chaining) using linked structures to eliminate memory allocation conflicts and maintain data persistence.
* **Algorithmic Complexity Optimization:** Designed custom hashing functions to evenly distribute data keys across arrays, keeping average-case data lookup time-complexity to O(1).
* **External Dataset Parsing:** Implemented file input streams and formatting parsers to ingest complex, external CSV data structures, converting ASCII text strings into structural data memory blocks.
* **Low-Level Resource Optimization:** Structured data allocations efficiently using C++ structure types (`struct Bid`) to balance computational performance and system memory constraints.
